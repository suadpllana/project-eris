# project-eris

Shipd Project Eris challenge workspace. Start with `CLAUDE.md`, which covers the platform rules, the accepted domains, the file contract, the novelty recipe and the form gotchas.

- `challenges/beijing-air-quality/`: From-Scratch Neural Forecasting of Air Quality at Unmonitored Sites (revision 2 ready, after reviewer feedback)
- `challenges/multilight-shadow-decomposition/`: Multi-Light Fractional Shadow Decomposition (Computer Vision)
- `tools/eris_check.py`: run before every submission, `python tools/eris_check.py challenges/<slug>`
